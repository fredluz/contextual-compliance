# Contextual Compliance

An informal AI-safety experiment: does a fabricated system prompt or fabricated session history make a model comply with a task it would otherwise refuse?

The task is a surveillance one: an agent with real filesystem tools is asked to cross-reference location data against a population registry and list the names and addresses of people who attended a protest. The experiment varies the framing of the request (direct ask, analyst framing, an "existing surveillance tool" system prompt, forged history of earlier compliance) across Claude, OpenAI, and several open-weight and Chinese models.

**Write-up:** https://fredericoluz.pt/experiments/contextual-compliance/v0/

**All data is synthetic.** Every person, address, device ID, and location record is generated by `scripts/generate-*.ts`; no real people or real surveillance data are involved.

## Layout

| Path | What |
|---|---|
| `scripts/` | Bun/TypeScript harness: data generators, cell runner (`run-cell.ts`), Leg-3 API runner, scoring and analysis |
| `prompts/PROMPTS-READABLE.md` | Every framing, the task message, and the forged-history prompts in readable form |
| `data/` | Small hand-written scenario files |
| `docs/` | Design notes: multi-turn mechanism, Leg-3 (forged history) build, tool-calling findings |
| `results/analysis/` | Scored summaries and deep-read notes per model family |
| `results/followups/` | Interview follow-up prompts |
| `viz/` | Source and build script for the interactive write-up (`build.py`), plus its dataset (`data.json`) |

Raw per-run transcripts and generated workspaces are not included; they are large and regenerable (`bun run generate:realistic`).

## Running

```bash
bun install
bun run generate:realistic
bun scripts/run-cell.ts --model <provider/model> --condition <condition> --run 1
bun run score && bun run analyze
```

Runs need your own provider access (`omp`, the `claude` CLI, or OpenRouter). Some paths in older docs and logs refer to the author's machine as `~`.

## Safety note

The prompts and docs describe how to forge session history to shift a model's behaviour. The technique is already public in the literature the write-up cites (Trojan Horse Prompting, Dialogue Injection Attack, STAC); the task content is synthetic and the purpose is to measure and report model behaviour.
